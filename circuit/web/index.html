⌁ Circuit debugging a pipelined CPU: solo, Baker Street, or a swarm

Who finds a hardware bug: one debugger, Holmes with his street boys, or a leaderless swarm?

The CPU is an 8-bit, 5-stage pipeline built from 96 blocks. Each bug number hides one bug (sometimes two) in one block: a stuck-at wire, swapped mux inputs, a wrong forwarding path or an off-by-one, some of them rare-trigger. The investigators only learn which registers end up wrong. Every probe costs 15 minutes of bench time, about one reading in twenty is glitched, and some boys and Irregulars are bribed. Someone must name the broken block, the signal, the bug type and the fix; the fix is graded by re-running every test.
